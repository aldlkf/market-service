# 🛒 Marketplace Service Backend

RESTful backend-сервис для платформы электронной коммерции (маркетплейса), спроектированный с акцентом на финансовую целостность транзакций, строгую ролевую модель безопасности, производительность и модульное тестирование.

---

## 🛠 Технологический стек

* **Язык & Фреймворк:** Java 21, Spring Boot 3
* **База данных & ORM:** PostgreSQL, Spring Data JPA, Hibernate 6
* **Миграции БД:** Flyway (V1–V4)
* **Безопасность:** Spring Security, Stateless JWT Authentication, BCrypt
* **Оптимизация:** Spring Cache (@Cacheable, @CacheEvict)
* **Тестирование:** JUnit 5, Mockito, MockMvc
* **Контейнеризация:** Docker, Multi-stage Dockerfile, Docker Compose
* **Документация:** OpenAPI 3.0 / Swagger UI

---

## 🌟 Ключевой функционал и Архитектурные решения

### 1. Безопасность и RBAC (Role-Based Access Control)
* Реализован кастомный фильтр аутентификации `JwtAuthenticationFilter`, проверяющий валидность подписанных токенов при каждом запросе.
* Разделение прав доступа:
  * **Публичные эндпоинты:** Регистрация, логин, просмотр каталога с поиском и фильтрацией.
  * **Пользователь (`USER`):** Управление личным профилем, пополнение баланса, корзина покупок, чекаут и просмотр своих заказов.
  * **Администратор (`ADMIN`):** Мутирующие операции над каталогом (создание, редактирование, удаление товаров), ручное управление жизненным циклом заказов.

### 2. Финансовая целостность и E-Commerce транзакции (@Transactional)
* **Атомарный Checkout корзины:** Оформление всех добавленных товаров выполняется в единой транзакции с валидацией остатков на складе, списанием баланса пользователя, формированием заказов со статусом `PAID` и атомарной очисткой корзины.
* **Отмена заказов:** При отмене заказа средства автоматически возвращаются на баланс покупателя, а складские остатки восстанавливаются.

### 3. Жизненный цикл заказов (State Machine)
Управление статусами заказов валидируется конечным автоматом состояний (`OrderStatus`):
* `PAID` → `SHIPPED` или `CANCELED`
* `SHIPPED` → `DELIVERED`
* Финальные статусы (`DELIVERED`, `CANCELED`) защищены от последующих модификаций.

### 4. Мягкое удаление товаров (Soft Delete)
* Настроены аннотации `@SQLDelete` и `@SQLRestriction("is_deleted = false")`.
* Удаленные товары не стираются физически из базы, сохраняя целостность исторических данных в таблице заказов, но автоматически скрываются из публичного каталога и поисковой выдачи.

### 5. Производительность и Кеширование
* Настроена абстракция Spring Cache для детальных карточек товаров (`@Cacheable`).
* Автоматическая инвалидация кеша (`@CacheEvict`) при обновлении информации или мягком удалении товара администратором.

## 📋 API Контракты (Ключевые эндпоинты)

| Метод | Эндпоинт | Доступ | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | Public | Регистрация нового аккаунта |
| `POST` | `/api/auth/login` | Public | Аутентификация и выдача JWT |
| `GET` | `/api/products` | Public | Каталог товаров (поиск, фильтр цен, пагинация, сортировка) |
| `GET` | `/api/products/{id}` | Public | Получение товара по ID (кешируется) |
| `POST` | `/api/products` | `ADMIN` | Добавление нового товара в каталог |
| `PUT` | `/api/products/{id}` | `ADMIN` | Обновление информации о товаре (сброс кеша) |
| `DELETE`| `/api/products/{id}` | `ADMIN` | Мягкое удаление товара (Soft Delete, сброс кеша) |
| `GET` | `/api/cart` | `USER` | Просмотр содержимого корзины с подсчетом общей суммы |
| `POST` | `/api/cart/items` | `USER` | Добавление товара в корзину |
| `DELETE`| `/api/cart/items/{id}`| `USER` | Удаление отдельного товара из корзины |
| `DELETE`| `/api/cart` | `USER` | Полная очистка корзины |
| `POST` | `/api/cart/checkout` | `USER` | Атомарная покупка всех товаров из корзины |
| `GET` | `/api/orders` | `USER` | История заказов авторизованного пользователя |
| `POST` | `/api/orders/{id}/cancel` | `USER` | Отмена заказа с возвратом средств и остатков |
| `PATCH`| `/api/orders/{id}/status` | `ADMIN` | Изменение статуса заказа (`SHIPPED`, `DELIVERED`) |
| `POST` | `/api/users/balance/top-up` | `USER` | Пополнение баланса пользователя |
